# Skill Atlas 官网

这是 Skill Atlas 的静态官网源码仓库，使用 React、TypeScript 和 Vite 构建，并通过 GitHub Pages 自动部署。

## 访问官网

[https://liangjie798.github.io/skill-atlas/](https://liangjie798.github.io/skill-atlas/)

本仓库仅包含官网相关代码和静态资源，不包含桌面应用源码、可执行文件或软件直链。

## 本地开发

```powershell
pnpm install
pnpm dev
```

## 构建

```powershell
pnpm lint
pnpm build
```
